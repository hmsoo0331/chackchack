계정 삭제 안내

착착 앱의 계정을 삭제하는 방법을 안내해 드립니다.

주의: 계정을 삭제하면 모든 데이터가 영구적으로 삭제되며 복구할 수 없습니다.

삭제되는 데이터

계정 삭제 시 다음 정보가 모두 삭제됩니다:

  • 회원 정보 (이메일, 닉네임, 로그인 정보)
  • 등록된 모든 은행 계좌 정보
  • 생성한 모든 QR 코드
  • 결제 알림 내역

앱에서 계정 삭제하기

  1. 착착 앱을 실행합니다.
  2. 메인 화면 우측 상단의 더보기 메뉴(≡)를 탭합니다.
  3. '계정 탈퇴' 메뉴를 선택합니다.
  4. 안내 내용을 확인한 후 '탈퇴하기'를 탭합니다.
  5. 확인 팝업에서 '확인'을 선택하면 계정이 삭제됩니다.

이메일로 계정 삭제 요청하기

앱에서 직접 삭제가 어려운 경우, 아래 이메일로 계정 삭제를 요청하실 수 있습니다.

  • 가입 시 사용한 이메일 주소
  • 가입 방법 (카카오, 네이버, 구글 등)

계정 삭제 후

  • 삭제된 계정으로는 더 이상 로그인할 수 없습니다.
  • 동일한 소셜 계정으로 다시 가입하면 새로운 계정이 생성됩니다.
  • 이전에 생성한 QR 코드는 더 이상 작동하지 않습니다.
