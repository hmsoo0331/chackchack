데이터 삭제 요청

착착 앱에서 수집된 개인 데이터의 삭제를 요청하는 방법을 안내해 드립니다.

사용자는 언제든지 자신의 데이터 삭제를 요청할 권리가 있습니다.

삭제 가능한 데이터 유형

데이터 유형 설명 삭제 방법
계정 정보 이메일, 닉네임, 소셜 로그인 정보 계정 탈퇴 시 자동 삭제
은행 계좌 정보 은행명, 계좌번호, 예금주명 앱에서 개별 삭제 또는 계정 탈퇴 시 삭제
QR 코드 생성한 QR 코드 및 관련 설정 앱에서 개별 삭제 또는 계정 탈퇴 시 삭제
결제 알림 내역 받은 결제 알림 기록 계정 탈퇴 시 자동 삭제

앱에서 데이터 삭제하기

개별 QR 코드 삭제:

  1. 메인 화면에서 삭제할 QR 코드를 선택합니다.
  2. '삭제하기' 버튼을 탭합니다.

모든 데이터 삭제 (계정 탈퇴):

  1. 더보기 메뉴(≡)를 탭합니다.
  2. '계정 탈퇴'를 선택합니다.
  3. 안내에 따라 탈퇴를 완료합니다.

이메일로 데이터 삭제 요청하기

특정 데이터만 삭제하고 싶거나 앱 이용이 어려운 경우, 이메일로 요청하실 수 있습니다.

요청 시 포함해야 할 정보:

  • 제목: [데이터 삭제 요청]
  • 가입 시 사용한 이메일 주소
  • 삭제를 원하는 데이터 유형
  • 요청 사유 (선택사항)

데이터 삭제 요청 이메일

support@chackchack.co.kr

요청 접수 후 영업일 기준 7일 이내에 처리되며, 처리 완료 시 이메일로 안내드립니다.

데이터 삭제 후 유의사항

  • 삭제된 데이터는 복구할 수 없습니다.
  • 법적 의무에 따라 일부 데이터는 일정 기간 보관될 수 있습니다.
  • 삭제된 QR 코드는 더 이상 작동하지 않습니다.
